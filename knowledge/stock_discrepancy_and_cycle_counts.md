# SOP-INV-05 Stock Discrepancies and Cycle Counts

## Reporting a discrepancy
If the physical count differs from system on-hand, do not adjust inventory yourself. Record the location, SKU, system quantity and counted quantity, then request a recount by a second operator.

## Recount and adjustment rules
A recount that confirms the difference triggers an adjustment request. Variances up to 2% of on-hand or 5 units (whichever is larger) can be approved by a shift supervisor. Larger variances need warehouse manager approval and a root-cause note.

## Cycle count frequency
Class A SKUs are counted weekly, class B monthly, class C quarterly. Any SKU with two discrepancies in 30 days moves up one class until three clean counts.
